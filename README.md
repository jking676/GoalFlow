# GoalFlow

GoalFlow is an executive-level, milestone-driven goal management application built with React, TypeScript, Tailwind CSS, and lucide-react.

## Features

- **Time-cascading hierarchy**: Annual Vision → Monthly Milestones → Weekly Commitments (max 5 active)
- **Dark-mode-first aesthetic**: slate-950 background, rounded-2xl cards, vibrant category accent badges
- **Five views**: Dashboard, Annual Vision, Monthly Milestones, Weekly Commitments, Weekly Review
- **Full CRUD**: Create, edit, and delete goals, milestones, and commitments
- **localStorage persistence**: All data stored locally with seed data on first load
- **Responsive design**: Sidebar on desktop, bottom navigation on mobile

## Goal Archetypes

- **Target Metric**: A measurable number to hit
- **Milestone Project**: A project with discrete deliverables
- **Condition / Event**: A specific event or condition to achieve
